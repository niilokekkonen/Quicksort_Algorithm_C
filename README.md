# Quicksort Algorithm in C
Quicksort algorithm found in the C++ expert book then reprogrammed in C.

# To run this program
- Make sure you have a C compiler installed, then open the file in IDE/Computer terminal.
- (IDE is preferred, because the program runs so fast the .exe file closes instatly, IDE keeps the output on the screen so you can see the output)

I'm using the integrated terminal in VSCode with Git Bash, and GCC to compile and run the program
 ```bash
 gcc quicksort.c -o quicksort.exe 

# Run the executable
./quicksort.exe
```
